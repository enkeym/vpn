# Юридические документы и организационный чек-лист

> ⚠️ **Это черновики-шаблоны, а не готовые юридические документы.** Все поля вида
> `{{ФИО}}`, `{{ИНН}}`, `{{контакт}}` нужно заполнить, а итог — показать юристу
> перед публикацией. Тексты отражают понимание законодательства РФ на 08.2026 и
> не являются юридической консультацией.

## Что уже сделано в коде

- **Фискальный чек (54-ФЗ / 422-ФЗ, НПД).** В платежи ЮKassa добавляется объект
  `receipt` (`src/payment/payment.service.ts`, `buildReceipt`). Контакт берётся из
  `RECEIPT_CUSTOMER_EMAIL`.
- **Тексты без рекламы обхода блокировок** (закон от 01.09.2025) — приветствия и
  тарифы переписаны на защиту/шифрование/приватность (`src/bot/ui/bot.ui.ts`).
- **Акцепт оферты и уведомление о ПДн** показываются перед оплатой
  (`legalNotice` в `bot.ui.ts`, ссылки из `LEGAL_OFFER_URL` / `LEGAL_PRIVACY_URL`).
- **Защита вебхука ЮKassa** от подделки IP (`trust proxy`, перепроверка статуса).

## Организационные действия (кодом не закрываются)

- [ ] **ФГИС Роскомнадзора.** Владельцы VPN-сервисов обязаны подключиться к ФГИС
      и фильтровать единый реестр запрещённых ресурсов. Юридически самый весомый
      пункт — оценить с юристом применимость к вашей модели.
- [ ] **Автофискализация самозанятого в ЮKassa.** Включить в ЛК ЮKassa привязку
      к «Мой налог», иначе `receipt` будет отклоняться. Задать
      `RECEIPT_CUSTOMER_EMAIL`.
- [ ] **Firewall на порт 3000.** При `network_mode: host` приложение слушает 3000
      прямо на хосте. Закрыть порт извне, оставив доступ только reverse-proxy
      (nginx/caddy с TLS для вебхука ЮKassa). Выставить `TRUST_PROXY_HOPS` под
      число прокси-хопов.
- [ ] **Публикация документов.** Разместить оферту и политику по постоянным URL и
      прописать их в `LEGAL_OFFER_URL` / `LEGAL_PRIVACY_URL`.
- [ ] **Реквизиты.** Заполнить плейсхолдеры (ФИО, ИНН, контакты) во всех файлах.
